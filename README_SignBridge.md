# SignBridge – Learn Sign Language

An accessible, single-page web app for learning basic sign language. Browse a sign dictionary, practice the fingerspelling alphabet, revise with flashcards, and test yourself with a quiz. Supports both **ASL (American Sign Language)** and **ISL (Indian Sign Language)**.

**Live demo:** https://kani-05.github.io/SignBridge/

<!-- Add a screenshot: ![SignBridge home page](screenshot.png) -->

## Features
- **Dictionary:** search signs and filter by language (ASL / ISL) and category (greetings, common words, numbers, questions, family, food, emotions).
- **Fingerspelling alphabet (A–Z):** switch between the ASL and ISL alphabets.
- **Learn mode:** interactive flashcards; your learned signs are remembered in the browser.
- **Quiz:** multiple-choice questions with a results screen.
- **Accessibility:** skip-to-content link, screen-reader announcements, keyboard navigation, and a light/dark theme.
- **No images needed:** hand signs are drawn as SVG illustrations in code.

## Built with
HTML, CSS, and vanilla JavaScript in a single file. Built with Google Antigravity (AI-assisted development).

## Run locally
Download `index.html` and open it in any modern browser. No installation or internet connection is required beyond the Google Fonts.
